# Inkwell Scanner — Backend

Backend API for the Inkwell Scanner Lorcana card-scanning app.

- **Stack:** Node.js + Express, SQLite (better-sqlite3), JWT auth, Stripe subscriptions.
- **Live code lives in `backend/`.** The `render.yaml` Blueprint at the repo root
  points at `backend/` (`rootDir: backend`).
- **Deploy:** see `backend/DEPLOY-RENDER.md`.
- **Stripe go-live:** see `backend/STRIPE-GO-LIVE.md`.
